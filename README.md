# CekDulu Frontend

Prototype frontend CekDulu untuk memeriksa indikasi risiko listing produk
Tokopedia. Aplikasi menggunakan Next.js, React, TypeScript, Tailwind CSS, dan
vinext untuk build berbasis Vite/Cloudflare Worker.

## Menjalankan secara lokal

Prasyarat: Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Perintah

- `npm run dev` menjalankan development server.
- `npm run build` membuat production build.
- `npm run lint` memeriksa source frontend.
- `npm test` memvalidasi production build.

Source halaman dan komponen berada di `app/`, sedangkan aset statis berada di
`public/`.
